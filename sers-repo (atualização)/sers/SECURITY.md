# Security policy

SERS is pre-release and **unverified**: do not use it to protect real assets yet (see `docs/LIMITATIONS.md`).

Reporting: a dedicated security contact has not been set up. Until one exists, report vulnerabilities privately
to the repository owner and do not open public issues for them.

Scope notes: SERS does not claim that reverse engineering is impossible. Reports that a privileged local
attacker can inspect a software-protected process are already documented limitations (`docs/THREAT_MODEL.md`, T17).
